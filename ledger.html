Paste data manually

If the live pull is blocked by your browser (common when opening the file directly from disk), paste a raw userFills JSON array here. You can also paste a journal export or a full backup (wallets + settings + journal) to restore it — the type is auto-detected.

CSV works too (fills from another venue or a spreadsheet): a header row plus columns for time, symbol, side (buy/sell), price, and size — fee and realized-PnL columns are used when present, otherwise position and PnL are derived by average cost. Name spot pairs like FOO/USDC; bare names reconstruct as perps.
